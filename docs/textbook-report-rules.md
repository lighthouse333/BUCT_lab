# 谢超然《大学物理实验》结果书写及程序规则

核对日期：2026-10-28。依据项目内[谢超然主编《大学物理实验》2015年扫描本](<../资料/大学物理实验 (谢超然主编；郎海涛，何惠梅副主编) (z-library.sk, 1lib.sk, z-lib.sk).pdf>)。以下“P”指印刷页；本PDF对应页序为印刷页+7。没有用其他版本的简介替代本书正文要求。

## 小数位不是全实验统一的常数

| 教材位置 | 要求 | 当前程序 |
| --- | --- | --- |
| P21–22，PDF28–29 | 不确定度一般1–2位有效数字；相对不确定度一般2位有效数字；结果末位与不确定度末位对齐 | 为统一页面，固定采用允许范围内的2位不确定度，取消选择控件 |
| P22，PDF29 | 中间不确定度计算可多留位，但一般不超过4位有效数字 | 计算不提前修约；中间显示通常最多4位，完整JSON仍留原数值 |
| P29，PDF36 | 模拟仪器、游标与数字仪器的读数规则不同；数字仪器读至显示末位 | 原始输入按仪器读数保存字符串，末尾0不删，不统一截成几位小数 |
| P30–31，PDF37–38 | 四舍六入五凑偶；5后全0时使保留末位为偶数 | 自行实现十进制half-even，不使用Math.round冒充教材修约 |
| P31–33，PDF38–40 | 加减看末位，乘除看最少有效数字；对数、指数及函数另有对应精度规则 | 计算留保护位，有完整不确定度的最终表达式按不确定度末位书写；未给完整精度依据的拟合/中间量展示约值，不将4位显示上限冒充通用最终规则 |
| P34，PDF41 | 表格标题、物理量符号、单位及有效数字明确，可列必要中间量 | 原要求的报告表式与单位保留；计算格只读 |

例如教材示例9.8065保留3位小数为9.806，3.1415为3.142，2.7182为2.718。结果示例(41.72±0.54)cm、(372.8±8.9)cm，分别需要2位、1位小数，不能都写成固定的小数位。

页面用真正的分式、根号和上下标排版；小量写成`4.303 × 10⁻²² J·K⁻¹`。百分差显示`|x−x₀|/|x₀|×100%`，给出参考值和数值代入；相对不确定度单独显示`U(x)/|x|×100%`，二者不混用。展示修约不反向覆盖测量数据或JSON数值。

P22要求测量值和不确定度单位、指数一致，并非所有长度必须写成m。当前显示按报告表式选择单位，单缝采用cm/mm/nm；数值、参考值和不确定度同步换算，原始数据和计算单位保留。结果页将每个物理量独立展示，展开后逐步列原式、数值代入与结果，全部左对齐；单位附在整个数值式之后，不能误排进分母或根号。传播项列具体物理敏感系数，换成同一结果单位后求平方和、开方及扩展。此分行/折叠方式是界面设计，未修约数值不因布局改变。

## 不确定度

教材P18–22采用课程tₚ表、u_A=tₚs/√n、u_B=Δ_ins/√3，通常报告U=2u。P21另列单次测量或重复读数完全相同的情况，按Δ_ins报告，不再额外乘2。程序固定这些规则，不再展示“标准/课程口径”或覆盖因子选择。

同值情况不省略判断过程：显示有效次数、同值说明、样本标准差为0、A类项为0、u_B≈Δ_ins及报告表达式。一般重复测量的A/B/扩展公式另标“本组未采用”，不能和本组报告值混用。只有一个有效值时无法估计样本标准差，不伪造s或A类统计值。光谱衍射角由四游标合成，仪器输入已经是换算到θ的标准不确定度，不再套用原始单读数误差限规则。

实际仪器误差、光杠杆D/b、纵向霍尔测量尺寸等仍须来自量具或实验记录，在录入页填写。未知仪器误差不默认为0；缺项时提示返回核对，不能把已知项合成值当作完整总不确定度。

## 自动图解点

P38–39（PDF45–46）要求从所画趋势线上取相距较远的两个非测量点求斜率；需要时取第三个非测量点求截距。程序自动化方式如下：

1. 使用所有有效实测点辅助建立直线趋势，不挑两个相邻测量点代替趋势线。
2. 在实测横坐标范围内约13%、87%处取P₁/P₂，约47%处取P₃；若重合测量横坐标，轻微移至非测量点。
3. 保留实际坐标、轴单位、来源标记；结果页列出选点、b=(y₂−y₁)/(x₂−x₁)、数值代入及a=y₃−bx₃。

教材没有要求“用最小二乘代替手工图解”；利用最小二乘辅助构造趋势线是本程序的实现。故图解与回归可能同值，不将其说成两次独立实验验证，也不把生成点当成新的实测数据。要求坐标纸、照片或手写报告的条款继续列在结果页。

导热冷却曲线采用稳态电压附近3条实际记录作局部线性近似，切点必须在记录范围内，斜率必须为负。显示这3条记录的原表行号及切线P₁/P₂；不使用整段冷却曲线回归冒充切线。

RLC从实测曲线自动找电压极大值，显示使用的原表行、频率及电压。边界极大值只表示测量范围内最大，提示补测，不能认定已测到真实谐振峰。

## 固定教材模型和来源边界

- 杨氏模量采用教材P71–72光杠杆式E=8FLD/(πd²bC)，D、b实填。
- 声速按P85–87：驻波相邻间隔λ/2；行波与李萨茹按同相重复位置，间隔λ。
- 扭摆按教材卸托盘测细杆、单滑块质量参考；霍尔采用教材载流子修正；PN使用线性U–t外推。
- 迈克尔孙基本式由P137–139确认；课堂原单的650.0nm优先于教材示例632.8nm。原单Δ_ins=0.00004mm当前固定按单次镜位置误差限，成对位移按独立项合成；0.5%计数项固定按报告层次的相对项，除2换为标准分量再传播。后两项的对象/覆盖含义是明确记录的程序约定，原单及已找到的教材页没有进一步明确，不能宣称均为教材逐字规定。结果页显示实际采用的处理依据，后续有专用课堂处理示例时应按原件复核。
- 单缝采用下载.pdf报告表1、表3；扫描表2明确无需誊录，实际光强图仍须提交。按用户2026-10-28确认的实验要求固定k=3，左右均填第3级暗纹位置；页面不能编辑级次，计算接口拒绝其他级次。符号使用xₖ、x̄ₖ下标。
- 只有记录图而没有完整报告网格的迈克尔孙不杜撰新表；偏振报告只有现象整理，保留用户已确认的表和图示。

## 对应代码

`report-precision.js`负责修约，`textbook-profile.js`负责固定模型，`formula-layout.js`及`components/math-formula/`负责原生公式，`uncertainty-presentation.js`提供完整不确定度步骤，`report-view.js`负责结果和选点展示。`scientific-notation.js`与`components/scientific-text/`统一各实验参数、表头、单位、坐标及公式文字的下标、次方；`components/scientific-input/`使原始科学计数值在非编辑时显示为“×10ⁿ”。大写F/H等使用真实下标布局，原始字符串和末尾零不改写。数值/表格/API边界见[计算接口说明](experiment-report-api.md)。
