# 01—06、PN 结实验的数据录入页

页面已接到现有首页。选择 01—06 或 14 后，点击“确认选择”即可进入。
光谱定性分析仍进入原来的页面，继续使用其原有计算功能。

## 文件分工

| 文件 | 用途 |
|---|---|
| `pages/experiment-input/index.wxml` | 七个实验共用的个人信息、参数与表格界面 |
| `pages/experiment-input/index.wxss` | 导入光谱页样式，补充录入表格样式 |
| `pages/experiment-input/index.js` | 输入事件、增减行、草稿、检查和复制 |
| `utils/experiment-input-config.js` | 各实验的字段、单位、模板预填值和表格定义 |
| `utils/experiment-input.js` | 校验、直接派生量、草稿恢复和统一数据出口 |
| `tests/experiment-input.test.js` | 录入、公式、保存与页面事件测试 |

共用路由：`/pages/experiment-input/index?id=实验ID`。
不复制七套相同的页面代码；`id` 决定加载哪一份记录表。

## 模板对应

字段及单位依据用户提供的《实验数据表汇总.xlsx》01—06、14 工作表，并与相应原始记录图片核对。

| ID | 表格 | 默认行数 |
|---|---|---|
| `young-modulus` | 加卸载读数、钢丝直径、逐差整理 | 10、5、5；第三张只读 |
| `kelvin-bridge` | 铜棒直径、定长电阻、变长度电阻 | 5、5、5 |
| `ballistic-galvanometer` | 两组电容比较、正反向高阻放电 | 8、8、5、5 |
| `thermal-conductivity` | 升温记录、稳态附近冷却记录 | 20、20 |
| `rlc` | R=200Ω 幅频、相频、R=20Ω 幅频 | 10、10、10 |
| `torsion-pendulum` | 圆柱直径、累计周期、滑块位置计时 | 5、5、6 个条件 |
| `pn-junction` | 恒温伏安、恒流温度与压降 | 20、20 |

扭摆第三张表在 Excel 中为 30 个长表记录；页面将其整理为“细杆基线＋5个滑块位置”共 6 行，每行填写 5 次 `5Tx`，逻辑上仍为同样的 30 次计时。
杨氏模量长度单位按汇总表采用 mm；扭摆质量采用 kg；RLC 相位采用 rad。
模板没有给出的实测数据与参数保持空白，不生成随机示例值。

## 输入与基础整理

- 输入支持负号与科学计数法；原始字符串保留，例如 `1.20` 不会在原始记录中变成 `1.2`。
- 空白与零分别处理，必填字段缺失时不能复制成完整数据。
- 用户可增减表格行；删除已填写的行需确认。杨氏加载表一次增减两行，以维持前后半组配对。
- 直接整理的量包括加卸载均值、正反电阻均值、周期换算、自然对数、开尔文温度与 RLC 的反正弦主值。
- 均值只在相关测量行全部有效时显示，不把漏填行自动排除后给出一个看似完整的均值。
- RLC 中 `B>A`、电流或取对数电荷为零、非递增的测量点等会明确提示。
- 杨氏逐差表显示配对起止序号。改变加载表行数时，按前后两半配对重新整理，完整处理仍需按实际课程验收。

开尔文 Rx 的仪器换算关系尚未提供；电容比较的正反向电荷均值也需要与课程符号约定确认。因此这些输出格保留“待计算”，数值为 `null`，不猜测物理公式，也不让用户手填来替代计算。

个人信息的班级、姓名、学号为完整数据交接前的必填项；日期、教师、同组人及实验步骤、现象、讨论可补充记录。未完整填写时可以保存草稿。

## 草稿

每个实验单独保存：`buct-lab:experiment-input:v1:实验ID`。
“保存本机草稿”可保存未完成的原始输入；正常离开页面时也尝试保存修改。
草稿仅在本设备，不含云端同步；强制结束应用前应手动保存。
恢复草稿时按当前模板重算派生量，忽略草稿中伪造的计算结果；不匹配的版本或异常行数不会直接加载。

## 数据出口

页面调用：

```javascript
const { collectPayload } = require('../../utils/experiment-input')
const result = collectPayload(this.data.form)
if (!result.ok) {
  // result.errors 包含表格、行、字段和可显示的说明。
  return
}
const payload = result.payload
// 在团队约定接口后，可将 payload 传给数据处理模块。
```

当前“检查并复制数据 JSON”仅复制并保存草稿，不会连接或上传到任何服务器。
通用结构：

```text
schema_version: lab-input-1
experiment_id: 稳定实验 ID
title: 实验名称
personal: name / class_name / student_id / experiment_date / instructor / partners
parameters: 每个参数的 value 与 unit
tables: 每张表的 id / columns / rows / derived
notes: actual_steps / observations / confirmed_error_notes
raw_input: 原始参数字符串与原始测量表，不包含自动计算格
collected_at: ISO 格式的收集时间
```

`tables[].columns` 包含字段 `key`、`label`、`unit`、`type`、`computed`。
`tables[].rows` 是数字化后的各行；文字说明保持文字，未实现的计算量为 `null`，不能当成 0。
后续计算应使用数值或原始输入，不要重新解析页面上用于核对的 8 位有效数字字符串。

PN 结额外提供 `payload.backend_input`，与已有 `PN结实验后端/core.py` 的 `analyze()` 输入一致：

```javascript
wx.request({
  url: YOUR_SERVER_URL + '/api/pn/analyze',
  method: 'POST',
  header: { 'content-type': 'application/json' },
  data: payload.backend_input,
  success(res) { /* 对接结果展示 */ }
})
```

PN 页面采用 V、μA、°C，恒流组为绝对正向压降模式。图解选点尚未在此录入页收集，现有后端会标记为待补；不要将调零后的电压差填入绝对压降列。

## 验证与边界

运行：

```powershell
node tests/experiment-input.test.js
node tests/spectral-analysis.test.js
```

已验证七套表格、单位、增减行、缺失/非法输入、原始精度保留、草稿隔离、页面事件、首页路由及 PN 数据出口。
同时使用本机微信开发者工具的 WXML、WXSS 编译器检查模板与样式，并执行编译后的 WXML，核对七项实验的输入格数量和循环绑定。
将已有 PN 示例数据经过新表单导出后交给 Python `analyze()`，得到的温度系数和禁带宽度与原示例结果一致。

尚未做微信真机上的键盘、滚动和系统剪贴板体验验收；这部分仍需在开发者工具和手机中检查。
本次实现是前端数据收集，不等同于七个实验的完整计算、图表、测量不确定度分析和报告生成均已完成。
