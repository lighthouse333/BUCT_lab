# 实验数据录入

首页保留光谱定性分析的独立页面，其余本轮开放的实验通过
`/pages/experiment-input/index?id=实验标识` 进入对应模板。

| 实验标识 | 实验 | 模板表格 |
| --- | --- | --- |
| hall-effect | 霍尔效应及其应用 | 变工作电流、变励磁电流、轴向磁场分布 |
| sound-speed | 声速测量 | 三种方法位置读数、逐差表 |
| strain-sensor | 应变式传感器的静态特性研究 | 单臂输入特性、全桥输入特性 |
| fresnel-biprism | 菲涅尔双棱镜测波长 | 5Δx、l₁、l₂测量 |
| polarization | 光的偏振 | 现象记录、四分之一波片 |
| single-slit | 单缝夫琅禾费衍射 | 衍射距离、光强扫描、暗纹位置与距离 |
| zeeman-effect | 塞曼效应 | 综合圆环、π线、σ线加场、σ线无场、偏振现象 |
| michelson | 用迈克尔孙干涉仪测单色光波长 | 等倾干涉波长测量、三组逐差、实验现象 |

模板依据用户提供的《实验数据表汇总.xlsx》中 07、08、09、10、12、13、15、16 工作表。
保留模板测量次数、预填测量点及单位，仪器参数可按实际情况修改。
声速的逐差配对固定为 1→6 至 5→10；迈克尔孙固定为 1→4 至 3→6。
这两项暂不开放增删测量行，以免使预设配对失效。

## 模块分工

- `utils/experiment-forms.js`：八个实验的参数、列、行和方案配置。
- `utils/experiment-input.js`：创建独立表单、输入校验、收集和复制原始数据。
- `pages/experiment-input/`：表格渲染、输入事件和错误定位。

蓝色格为原始输入，固定项目只读。U_H、B、逐差、校准均值、拟合值、残差、
圆环直径等列保留为只读“待计算”，不要求用户填入处理结果。

所有原始值均按字符串保存，例如 `0.12000` 和 `-1.20` 不会在录入时转换或修约。
数值检查支持符号、小数和科学计数法；空字符串与零分别处理。
“检查输入”验证当前方案的必填原始数据和参数，选填内容有值时仍检查格式。
此检查不验证实验公式适用性或结果准确性。

塞曼方案切换保留当前页面的全部已填内容，但检查和复制只包含当前方案及公共现象表。
恢复空白模板会清空所有方案的读数。删除已填行及恢复模板前均弹出确认框。
本轮未实现持久化；离开页面后不保留数据，可先复制原始数据。

光的偏振不预填实际观察、轴方向、结论或偏振态；名义角预填为 0° 至 90°，
每隔 15° 一组，实际角单独录入。文字记录为必填，不适用项可以写“不适用”。
单缝衍射默认 3 组距离、50 点扫描及 5 级暗纹；扫描表可增至 200 行，
其他可增删表格默认上限仍为 60 行。暗纹的左距、右距及平均距离保持只读待计算。

## 后续计算接口

调用 `collectInput(page.data)` 获得：

```js
{
  experimentId: 'michelson',
  schemaVersion: 1,
  mode: '',
  info: { studentClass: '', studentName: '', studentId: '', date: '', teacher: '' },
  parameters: { /* 参数标识: 原始字符串 */ },
  tables: [
    { id: 'positions', rows: [{ number: '1', order: '0', position: '0.12000' }] },
    // 此处仅演示一行；实际包含当前方案的全部表格与全部行。
  ]
}
```

返回对象不包含处理列。先完成输入检查，再由计算模块转换数字、处理单位及公式条件；
计算结果应另行管理，不覆盖原始输入。

## 验证

使用 Node.js 执行 `node --test tests/spectral-analysis.test.js tests/experiment-input.test.js`。
覆盖测量点、行列数、参数、负数和小数精度、方案切换、增删与重置确认、错误定位及页面路由。
另使用本机微信开发者工具内置 WXML / WXSS 编译器检查页面语法。
真机上的键盘、滚动和布局仍需在微信中检查。
