## 参数与记录规则

霍尔励磁系数修正为2.25e-2 T/A；输入励磁电流仍用mA，计算B时须除以1000换A。
500mA在该系数下对应0.01125T。亥姆霍兹线圈与长直螺线管的K_H不能混用。
电导率/迁移率需要纵向电压、电流、接点距离及样品宽度，现于参数栏填写实际测量值；不编造额外的原报告网格。

杨氏原长L按原件使用cm，默认89.00。扭摆质量统一kg，页面提示由g换算；
10T₀、10T₁、5T_x均保存累计时间，不在录入时换算成单周期。
积分电流计保留正反向电量原始符号及实测时间：存在正反异号实测值时用带符号半差，否则用正幅值平均；矛盾的符号记录会报错，不直接取绝对值掩盖问题。

杨氏模量固定使用教材光杠杆公式，实际D、b及量具误差在录入参数栏填写。
其他需要不确定度的实验也在录入页提供相应量具误差字段，未知误差不默认成0。
这些是实际测量信息，结果页不再要求另选模型或人工输入图解点。

固定次数的报告表保持对应测次。导热和PN恒流表有省略号，
可按实际测量增加记录：未使用的全空行不参与检查/导出，
半填行必须补齐，每张这样的表至少需要一组实际记录，零值不算空白。
单缝使用报告表1、表3；光强扫描表2不再列为本页必填表，实测光强图仍须按要求另行绘制、提交。
RLC可增加谐振附近频点，相位符号记录是选填辅助信息。

偏振恢复原表4个可见列：波片光轴角度、OA实际角度、长短轴图示、观察现象。
预印的文字、方向图和填空保留；45°仅填实际角度，不强制填写原件没有的光轴关系。
预印参考内容不当成用户实测答案导出，实际观察如有补充可另行填写。
报告要求按原件列出实验步骤、现象整理及手工整理要求，另显示该实验明确的提交条款。

塞曼保留综合、π、σ方案选择；π/σ各4行方向箭头交替。
现象记录含横向0°/90°/180°/270°以及正反平行45°/135°等实际记录条件。
使用报告页的空白实际现象栏，不将原始记录页的预印说明当作使用者实测。
综合版位置后增加各环直径，平均行只统计直径；分析及结论栏保留，仍须按要求手写。
切换方案保留所有内容，检查和导出只包含当前方案及公共现象表、适用参数。

迈克尔孙保留独立的调零位置和首点n=0的镜位置，不能自动互相代替。
白光中央条纹的镜位置独立记录；等倾、单色等厚、白光条纹现象需填写。
原表前三个逐差格为横线，后3格配对1→4、2→5、3→6；对应计算显示在结果页。
完整处理示例与提交要求缺少原件的部分保持待核对，不套用通用规则。

## 光谱独立页面

原始表和θ处理表分别显示，默认3次测量；保留左右游标、±1级分组及平均位置。
刻线密度默认300条/mm，光栅常数相对标准不确定度默认0.1%。

角度样本统计沿用指定教材tₚ表，传播时转为rad；
在各项独立的条件下，计入光栅常数及角度A类、仪器标准不确定度。
角度仪器项需填写已经换算到θ的标准不确定度，不是原始游标误差限。
未填写仪器项，或A类项无法估计时，只显示已知项合成值并注明不完整，
不能把该数值当成完整总不确定度。仪器项明确填0也仍保留光栅常数贡献。
同值重复测量的A类为0不意味着总不确定度为0。

现象和发光元素分析单独记录并包含在复制内容中，不根据一条谱线自动认定元素。
独立页仍保留原有即时计算，底部“开始计算 · 查看报告数据”接入统一结果页，
其中最终报告表达式与不确定度按计算模块规则修约。

## 数据接口与兼容性

collectInput(page.data)返回schemaVersion: 3、templateVersion: "2026-10-28-report"。
所有原始输入仍为字符串，保留0、负号、正号、科学计数法及末尾零。
返回当前方案的参数和表格，不包含计算列、预印参考答案或未使用空行。
本次从2升级到3，是因为单缝改为报告表3、声速改为分方法逐差表，
其他表式增加派生格。版本1/2不能直接传入新计算器；后续导入必须检查版本与单位。

collectInput中的tables按测次保存，与屏幕上横向还是纵向无关。
复制使用带列名的文本，保留原始精度，预印现象单独注明“原表预印”。
检查通过仅表示填写及数值格式通过，不等于实验结果正确或报告已完成。

删除已填写记录及恢复模板有确认。记录仅在页面内存保存，
从结果页返回可继续修改原表；退出录入流程或关闭小程序前请复制所需内容。
拍照、Excel导入、持久化及PDF/Word报告导出尚未实现。
