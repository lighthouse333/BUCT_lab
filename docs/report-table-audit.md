## 单缝表3与公式对应

| 原件列 | 输入/计算 |
| --- | --- |
| 主极大左侧k级极小位置 k左/mm | 实填left |
| 主极大的中心位置 O/mm | 实填center |
| 主极大右侧k级极小位置 k右/mm | 实填right |
| 左侧极小与中央的距离 xₖ左/mm | center−left |
| 右侧极小与中央的距离 xₖ右/mm | right−center |
| k级极小与中央的平均距离 x̄ₖ/mm | (right−left)/2 |

必须满足left<center<right。按用户2026-10-28确认的实验要求固定k=3，左右均取第3级暗纹；λ=a·x̄ₖ/(3z̄)，单位换算后输出nm。页面以只读文本显示3，输入及计算接口均拒绝其他级次，不能将旧的其他级次位置直接当第3级使用。xₖ、x̄ₖ直接以下标显示。光强图仍须按报告要求提交；程序不会凭三项位置虚构扫描曲线。

## 计算与数据边界

- 所有计算格只读，即时派生；原始字符串与末尾零保持不变。清空读数后清除关联计算值。
- `collectInput`输出schemaVersion=3，只含测量输入，不回传计算格或纯派生表。版本1/2必须按新表重新填写，禁止静默混算。
- `calculateReport`输出reportSchemaVersion=2及`reportTables`，保留报告表的标题、原编号、列、版式、行与平均栏；输入页、结果页和文本输出共用这套表数据。原`tables`保留为辅助计算明细。
- 固定采用教材方法，取消结果页的计算条件选择；D/b、仪器误差等实际测量量在录入页填写，未知量保留待补状态。图解点自动生成并标明；现象、手写分析、签字和图像提交仍由使用者完成。
- PDF原件优先于汇总Excel和Word；新发现的独立记录单不覆盖本次明确指定的报告处理表。
- 修约、自动选点及教材没有明确的来源边界，见[教材规则](textbook-report-rules.md)。
