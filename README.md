# -----项目综述-----

## 项目名称

```BUCT_lab```

一款适配北化学生大学物理实验的实验数据处理工具，百花学生可通过微信小程序`暂缺`打开使用。

## 项目背景

开发者注意到北化学生时常为大学物理实验的实验数据处理而发愁或者因此而花费数小时的时间处理实验数据，基于此，本项目开发了一款适配百花学生的实验数据处理工具，包含百花大学物理实验所要求的约二十课程的实验数据处理器。

## 项目特色

免注册，免登录，开箱即用的大学物理实验数据处理工具，只要你有微信，找到你需要处理实验数据的课程，填入相关数据，即可获得处理好的实验数据，更有相关实验报告模版供你参考。

项目高度适配百花大学物理实验教材，精准解决学生数据处理难题。
